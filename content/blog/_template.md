Copy this file, rename it to the article's web address (for example `how-to-plan-reels.md`) and
remove the underscore. Files that start with an underscore are ignored by the build.

Category can be Video, Marketing, Branding, Social media, Web or Agency. Use a higher `order`
than the newest article so the new one appears first.

## Use two hashes for a section heading

Sections appear in the "On this page" list next to the article.

### Three hashes for a smaller heading

- Start a line with a dash for a bullet list.
- **Two stars** make text bold.

1. Start lines with numbers for a numbered list.
2. [Link text](https://example.com) makes a link. Use {{root}}contact.html to link to a page on this site.
